## 4. 作成時に判断したこと

- **タイトルは A案を推し**にしました。理由は、検索語「行基」を【奈良時代】の直後に置いたこと、「橋・ため池・大仏の勧進」という教科書語を含むこと、前作『奈良の光／聖武天皇』と同じ「〈語〉／歌で覚える〜」の並びでシリーズとして揃うことの3点です。
- **717年（弾圧の詔）と745年（大僧正の任命）は、歌詞に出てこないため説明欄側にだけ記載**しました。歌詞中の年号（668・743・749）と混ざらないようにするためです。
- **史実と伝承を書き分け**ました。「文殊菩薩の化身」は伝承、渡し守は説話、「2年で寺を15」は逸話、と明示しています。
- **大仏開眼供養（752年）が行基の没後である点**は、フル版・ショート版・TikTok の3か所すべてに入れています。曲だけを見た人が誤解しないための保険です。
- トーンは「です・ます」調、絵文字なし、煽り文句・誇張なしで統一しました。
