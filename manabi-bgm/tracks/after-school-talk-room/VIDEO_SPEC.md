## 解像度についてのメモ

1264×720 は 720p としては**横が16px短い**（標準は1280×720）。
これは制作時の素材アスペクトによるもので、YouTube は問題なく受け付け、720p として配信されます。

次作以降で 1280×720 に揃えたい場合は、**この曲の再エンコードはせず**、次作の書き出し設定で対応してください。
既存の高画質版に再エンコードをかけると画質が落ちます。

## 検品手順

復元した高画質版に対して行います。

### 1. ファイルの同一性

```sh
shasum -a 256 "放課後トークルーム_1時間_高画質版.mp4"
# => 118de0f31bca5de2386e4099df674d67cc40a59dbf9ddf11443b887211605cfc
```

### 2. 仕様の確認（ffprobe がある場合）

```sh
ffprobe -v error -show_entries format=duration,size,bit_rate \
  -show_entries stream=codec_name,width,height,r_frame_rate,sample_rate,channels \
  -of default=noprint_wrappers=1 "放課後トークルーム_1時間_高画質版.mp4"
```

期待値：`codec_name=h264` / `1264×720` / `r_frame_rate=24/1` / `codec_name=aac` / `sample_rate=48000` / `channels=2` / `duration≈3600.08` / `size=679926904`

### 3. ラウドネスの確認（任意）

```sh
ffmpeg -i "放課後トークルーム_1時間_高画質版.mp4" -af ebur128=peak=true -f null - 2>&1 | tail -20
```

期待値：Integrated ≈ -14.6 LUFS / True peak ≈ -1.0 dBFS

### 4. 目と耳での確認（必須）

次の5点を再生して、**音切れ・映像の跳び・音量の急変**がないことを確認します。

- [ ] 0:00（頭。無音から始まっていないか）
- [ ] 0:10
- [ ] 1:59 前後（ループの継ぎ目が出やすい位置）
- [ ] 30:00（中間）
- [ ] 59:55（終端。尻切れしていないか）

### 5. サムネイル

- [ ] 文字がスマホ表示でも読める
- [ ] 1280×720 以上・2MB以下・JPG/PNG（YouTubeの要件）
