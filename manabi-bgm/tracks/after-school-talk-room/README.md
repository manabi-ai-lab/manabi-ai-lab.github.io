# 放課後トークルーム（After School Talk Room）

manabi-ai-lab BGMシリーズ **第1作**。

放課後の教室で、友だちとゆっくり話しているような時間をイメージした、やさしく明るいインストゥルメンタルBGM。
**会話やナレーションを邪魔しにくい**ことを最優先に設計しています。
