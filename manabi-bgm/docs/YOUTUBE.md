# YouTube投稿手順（シリーズ共通）

曲ごとの投稿文・タグは `tracks/<slug>/YOUTUBE.md` が正本です。この文書は**手順**だけを扱います。

第1作の投稿文 → [`../tracks/after-school-talk-room/YOUTUBE.md`](../tracks/after-school-talk-room/YOUTUBE.md)

---

## 0. アップロード前の確認

- [ ] 高画質版の SHA-256 を照合済み（[`RESTORE.md`](RESTORE.md)）
- [ ] スマホDrive版（HEVC・約101.6MB）**ではない**ことを確認した
- [ ] サムネイル画像が手元にある
- [ ] `tracks/<slug>/YOUTUBE.md` の投稿文が確定している

> **ログインについて**
> YouTube のログインが必要な場面は、**あっきーが自分で操作**します。
> AIにアカウントのパスワードを渡す必要はありませんし、渡さないでください。

---

## 1. アップロード

1. <https://studio.youtube.com/> を開く
2. **作成 → 動画をアップロード**
3. `放課後トークルーム_1時間_高画質版.mp4` を選ぶ
   - 649MiB・1時間なので、処理完了まで時間がかかります
   - **HD処理が終わるまで公開しない**（先に公開すると低画質でしか見られない時間が生まれます）

## 2. 詳細

| 欄 | 入れるもの |
| --- | --- |
| タイトル | `tracks/<slug>/YOUTUBE.md` のタイトル |
| 説明 | 同ファイルの概要欄。**最後の「この動画のURL」は後で置換** |
| サムネイル | `assets/thumbnails/<slug>.jpg` |
| 再生リスト | 配信・動画用BGM |
| 視聴者 | **子ども向けではない** |
| 年齢制限 | なし |

## 3. 「動画の要素」

- 終了画面・カードは任意。1時間BGMでは付けなくてよい

## 4. チェック（重要な設定）

| 項目 | 設定 |
| --- | --- |
| **改変・合成コンテンツ** | **はい** |
| 有料プロモーション | なし |

> AI生成音楽を含むため、開示は **はい**。透明性を優先するのがこのシリーズの方針です。

## 5. 公開設定

**最初は必ず「限定公開」**。

限定公開のまま、次を確認します。

- [ ] スマホで再生できる
- [ ] PCで再生できる
- [ ] HD（720p）が選べる状態まで処理が進んだ
- [ ] 0:00 / 0:10 / 1:59前後 / 30:00 / 59:55 に音切れ・映像の跳び・音量の急変がない
- [ ] サムネイルの文字がスマホ表示で読める

## 6. 詳細設定（「すべて表示」の中）

| 項目 | 設定 |
| --- | --- |
| カテゴリ | **音楽** |
| ライセンス | **標準のYouTubeライセンス** |
| コメント | オン |
| **自動チャプター** | **オフ** |
| 動画の言語 | 日本語 |
| 収益化 | 利用可能ならオン |

> 自動チャプターは「すべて表示」→「自動チャプター」の中にあります。
> 単一BGMでは意味のない章立てが作られるので**必ずオフ**。

## 7. 公開後

1. 概要欄の「この動画のURL」を**実URLに置換**
2. 固定コメントを投稿してピン留め
3. `tracks/<slug>/YOUTUBE.md` の「記録欄」にURLと日付を記入
4. GitHub Release のノート末尾に YouTube URL を追記
5. リポジトリ README のシリーズ一覧を更新

---

## 8. 限定公開 → 一般公開

上のチェックがすべて通ってから切り替えます。急がなくて構いません。
切り替えたら `tracks/<slug>/YOUTUBE.md` の記録欄に日付を書きます。
