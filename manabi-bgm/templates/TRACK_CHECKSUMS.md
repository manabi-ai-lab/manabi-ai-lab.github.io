## 配布してはいけないファイル

| ファイル | 理由 |
| --- | --- |
| `<曲名>_<尺>_スマホDrive版.mp4` | 受け渡し用に強く圧縮した低画質版 |

サイズが原本と違う、あるいは SHA-256 が一致しないファイルは**すべて配布対象外**。

## 照合のしかた

```sh
shasum -a 256 "<ファイル名>"                                  # Mac / Linux
Get-FileHash "<ファイル名>" -Algorithm SHA256                 # Windows
```
