# 「祇園精舎 -The Rise and Fall-」制作環境監査（2026-09-19）

## この文書の位置づけ

これは作品の制作正本や `CURRENT_STATE.md` の代替ではない。制作本体へ接続できない環境で、誤ったリポジトリへの素材投入や重複生成を防ぐために行った、読み取り専用の入口監査記録である。

## 確認結果

- 現在の作業ディレクトリは `manabi-ai-lab.github.io` で、チェックアウト中のブランチは `work`。
- ローカル Git に remote は設定されていない。
- この作業ツリーには、指定された `content/projects/heike-gion/`、制作正本、試写素材、音源、字幕設計、QA 記録は存在しない。
- GitHub CLI はインストール済みだが、GitHub ホストへ未認証のため、非公開制作リポジトリ、対象ブランチ、Draft PR の現況を取得できない。
- Drive 用 CLI／MCP リソースは構成されていない。シェルからの外部接続もプロキシで拒否されたため、Drive 上の現物を取得・計測できない。
- このため、生成数、実受領数、採用数、書き出し数、QA 確認数はすべて未確認。動画の bytes、SHA-256、寸法、尺、fps も未確認。

## 実施した安全措置

- 別作品・別リポジトリへの誤投入を避けるため、画像・音源・動画の生成、ダウンロード、変換、書き出しは行っていない。
- 同名の制作フォルダや `CURRENT_STATE.md` は新設していない。
- 原曲、原詞、年代表記、既存素材には変更を加えていない。
- main の更新、merge、公開投稿、課金、認証・セキュリティ設定の変更は行っていない。

## 再開条件と最小手順

次回は、非公開制作リポジトリと作品 Drive を読み取れる実行環境で開始する。接続後は次の順で進める。

1. 制作リポジトリの `AGENTS.md` と指定正本を読み、対象ブランチおよび Draft PR の現在状態を確認する。
2. Drive と Git の台帳を突合し、A 横・A 縦・B 横・B 縦の現物について bytes、SHA-256、寸法、尺、fps、デコード可否を記録する。
3. 不足分だけを制作し、原曲・字幕を合わせた 10〜15 秒の横／縦 MP4 を書き出す。
4. 機械検証、静止フレーム視覚確認、音付き通し視聴を分けて記録し、制作正本の `content/projects/heike-gion/CURRENT_STATE.md` を更新する。

認証情報そのものを Git に保存してはならない。
