# ackey1007fw-coder.github.io

「まなびのうた」— 教育 × AI の制作記録サイト。

https://ackey1007fw-coder.github.io/

静的HTML1枚とCSS1枚。ビルド不要で、`main` に push すると GitHub Pages に反映される。

制作物の設計図・手順書・スクリプトは別リポジトリ（非公開）で管理していて、
このサイトにはその結果と、実際に詰まった箇所の記録だけを載せている。

## 更新のしかた

`index.html` を直接編集する。作品が増えたら `#works` のカードを1枚足し、
制作で新しく詰まったことがあれば `#making` に `.memo` を1つ足す。
