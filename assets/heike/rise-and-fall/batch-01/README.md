# 「祇園精舎 -The Rise and Fall-」原画 Batch 01

初回バッチは、枠物語2場面と歴史本編4場面の計6場面です。各原画は16:9の独立した一場面とし、コラージュや画面内文字を使用しません。

## 制作順

1. `A01` 夕映えの縁側――語りの始まり
2. `A02` 祇園の鐘――無常の響き
3. `B01` 平家の栄華――大輪田泊の繁栄
4. `B02` 都落ち――燃える夕空の行列
5. `B03` 熊谷直実――刃を止める苦悩
6. `B04` 那須与一――扇を射抜く一矢

生成仕様、人物ロック、禁止事項、各場面の役割とプロンプトは [`manifest.json`](./manifest.json) を正本とします。生成前に承認済み画像群をスタイル参照として接続し、生成後は人物・衣装・時代考証・手指・武具・琵琶・文字混入を目視検品します。

## 採用条件

- 1枚で1場面として成立している
- こよみの制服と紫の花が正本設定に一致している（Aカットのみ）
- 琵琶法師の黒衣・編み笠と琵琶の基本形が保たれている（A01のみ）
- 歴史本編に現代人物が混入していない
- 夕景・黄金色の光・歴史アニメ映画調が全場面で統一されている
- 画面内に文字、ロゴ、透かしがない
- 不自然な手指、武具、馬具、船体、楽器がない

不採用画像は完成数に含めません。採用画像だけを上記の `file` 名でこのディレクトリに保存します。
